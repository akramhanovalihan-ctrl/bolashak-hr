# ЗП ведомость — требования из Telegram + Google Sheets

Источник:
- Скрины Telegram (16:25–16:28): табель → ведомость для Талшын
- Таблица: https://docs.google.com/spreadsheets/d/1bN3fTi1D42ExdHRg_Ax_QyMzMJgAsyC9knYopJKdKh4/edit?gid=1542716394

## Процесс (как должно работать)

1. **Руководитель** — отдельный вход, заполняет табель каждый день (сотрудники + должности из списка)
2. **Табель сдаётся** → HR утверждает
3. **После утверждения** — часы, штраф, аванс автоматически попадают в ЗП ведомость
4. **Талшын (HR)** — вручную проставляет:
   - Оклад
   - Плановые часы по должности
   - **Отчисления** (колонки из Google Sheets)

## Реализовано

- Вкладка **«Отчисления»** в ЗП ведомости: редактирование оклада, плана ч, отчислений, бонусов (роли admin/hr/finance)
- Штраф и аванс — только из табеля (read-only)
- При **утверждении табеля** — автосинхронизация ведомости по подразделению
- Итого пересчитывается: начислено − аванс − штраф − отчисления + бонусы
- HR-правки (оклад, план, отчисления) сохраняются при повторной синхронизации
