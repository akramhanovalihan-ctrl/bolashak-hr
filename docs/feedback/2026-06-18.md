## Вопросы пользователя

| # | Вопрос | Ответ |
|---|--------|-------|
| 1 | Почему «рук-ль ком. отдела»? | Ошибка в тексте интерфейса из старого ТЗ. Исправлено: «Справочник подразделений с назначенным руководителем». |
| 2 | Шемонайха, Зеленый — закрыты | Скрыты из справочника (`is_active = 0`). |
| 3 | Глубокое, Калбатау, Самарское — партнёры | Переименованы: «партнер Глубокое», «партнер Калбатау», «партнер Самарское». Тип: «Партнёр». |
| 4 | Список ФИО не выпадающий | В табеле — обычный `<select>` со списком сотрудников подразделения (не поиск). |
| 5 | Пересмотр оклада влияет на старые месяцы? | **Нет.** Оклад в карточке — текущий. В ведомости за месяц хранится снимок `monthly_salary`; при повторной синхронизации он не перезаписывается. Меняется только для новых месяцев или если HR ещё не зафиксировал оклад в ведомости. |

## Логическая цепочка (как должно работать)

```
База сотрудников (карточка: ФИО, должность, подразделение, оклад)
        ↓
Табель (руководитель: выбор из списка, часы, штраф, аванс)
        ↓ сдать → HR утверждает
ЗП ведомость (авто: факт ч, штраф, аванс из табеля)
        ↓
HR вручную: оклад, план ч, отчисления, бонусы (вкладка «Отчисления»)
        ↓
Итого к выплате
```
