## Блок A — Подразделения

- [ ] Подзаголовок без «(ком. отдела)»
- [ ] **Шемонайха** и **Зеленый** не отображаются
- [ ] Есть: **партнер Глубокое**, **партнер Калбатау**, **партнер Самарское**

## Блок B — Табель (руководитель / admin)

Подразделение **АУП**, любой черновик месяца.

- [ ] Колонка **ФИО** — выпадающий список (не поиск)
- [ ] «+ Строка» — тоже список сотрудников подразделения
- [ ] Нет строк с ручным текстом без ФИО из базы
- [ ] Часы в ячейках: 8, 4, 7.5 или код из легенды
- [ ] **Сохранить** → **Сдать табель**

## Блок C — Утверждение (HR: talshyn@bolashak.local / hr123)

- [ ] Табель со статусом «Сдан» → **Утвердить**
- [ ] Статус «Утверждён»

## Блок D — ЗП ведомость (HR)

Тот же месяц и подразделение **АУП**.

- [ ] В фильтре только конкретное подразделение (не 99 человек)
- [ ] **Факт ч**, штраф, аванс совпадают с табелем
- [ ] Вкладка **«Отчисления»**: оклад, план ч, отчисления редактируются
- [ ] **Обновить** пересчитывает без потери введённых HR полей
- [ ] Итого сходится с вашей Google-таблицей

## Блок E — Оклад и прошлые месяцы

- [ ] Изменили оклад в карточке сотрудника
- [ ] Старый месяц в ведомости **не изменился**
- [ ] Новый месяц подтягивает новый оклад (или HR вводит вручную)
